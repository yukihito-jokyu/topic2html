## プロダクト目標

管理者が自然言語で技術トピックを入力し、視覚的な解説HTMLを得る。管理者は結果を確認、修正、整理、公開でき、未ログインの閲覧者は現在公開中の版だけを閲覧できる。

## アクター

| アクター | 責務 |
| --- | --- |
| 管理者 | 生成、確認、修正、整理、版選択、公開承認、非公開化 |
| 閲覧者 | 現在公開中の解説HTMLの閲覧 |
| Codex app-server | 初回および修正時のHTML生成 |
| Google本人確認サービス | 事前登録された管理者メールアドレスの本人確認 |

## システム境界

対象は、管理者認証、生成と再試行、HTML形式検証、版と試行履歴、整理、公開、閲覧、生成HTMLの隔離表示である。Codex app-server、Google本人確認サービス、生成HTMLから接続される外部サイトはアプリケーション境界の外部にある。

## 主要制約

- 初期リリースの生成基盤はCodex app-serverに固定する。
- 管理者は事前登録済みGoogleメールアドレス1件だけとする。
- 管理者プレビューと公開表示の双方で、生成HTMLを信頼しない。
- 共通の機械的合格条件はHTML形式である。内容の正しさと分かりやすさは管理者が判断する。
