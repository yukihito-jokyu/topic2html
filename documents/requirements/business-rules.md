# 業務ルール

すべての情報源はGitHub issue #87、状態はconfirmedである。

| ID | ルール |
| --- | --- |
| BR-001 | 初期リリースの管理者は、事前登録されたGoogleメールアドレス1件の利用者だけである。 |
| BR-002 | アプリ独自の対象外トピック分類はせず、生成基盤の制約は通常の生成失敗として扱う。 |
| BR-003 | HTML形式に合格した出力だけを解説HTMLの版とする。 |
| BR-004 | HTML検証に失敗した出力には、タグ・掲載場所・公開を設定できない。 |
| BR-005 | 自動再生成は最大3回で終了する。 |
| BR-006 | 解説コンテンツは複数の合格済み版を持てる。 |
| BR-007 | 同一コンテンツで同時に公開される版は1つだけである。 |
| BR-008 | 新しい版を作成しただけでは公開版を変更しない。 |
| BR-009 | 新版が未承認の間は従来の公開版を表示し続ける。 |
| BR-010 | 過去版を公開版に選択する操作は、その版の公開承認を兼ねる。 |
| BR-011 | 非公開化後は、以前の公開版を含め閲覧者から到達できない。 |
| BR-012 | タグと掲載場所は版ではなく解説コンテンツに属する。 |
| BR-013 | 公開版を切り替えてもタグと掲載場所を維持する。 |
| BR-014 | 少なくとも1つの合格済み版を持つコンテンツだけにタグ・掲載場所を設定できる。 |
| BR-015 | 閲覧者へ未承認版、過去版、版履歴、生成試行、失敗記録、管理情報を表示しない。 |
| BR-016 | 失敗要約に詳細な内部ログ、資格情報、秘密値、内部データを含めない。 |
