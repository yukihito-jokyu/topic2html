# 非機能要件

| ID | 要件 |
| --- | --- |
| NFR-001 | 生成HTMLは認証情報、セッション、秘密値、接続情報、管理画面・保存領域・操作へ到達できない。 |
| NFR-002 | この隔離は管理者プレビューと公開表示の双方へ適用する。 |
| NFR-003 | 生成HTMLは未公開HTML、版履歴、生成試行、失敗記録、詳細ログ、Codex・Google機能をアプリの権限で利用できない。 |
| NFR-004 | 外部通信は許可するが、アプリの資格情報・管理者セッション・秘密値・管理データを付与しない。 |
| NFR-005 | 外部通信の失敗は許容する。 |
| NFR-006 | 生成完了時間は保証しない。 |
| NFR-007 | 特定のブラウザや端末での表示は保証しない。 |
| NFR-008 | 数値で判定するアクセシビリティ基準は設けない。 |
| NFR-009 | 学習効果は受け入れ条件にしない。 |
| NFR-010 | 内容の正しさと分かりやすさは管理者が表示を確認して判断する。 |
