# トピック解説HTML生成・管理Webアプリ 要件定義

- 状態: 確定
- 最終更新: 2026-08-11
- 対応する議論マップ: [topic-to-html-requirements-discussion-map.md](./topic-to-html-requirements-discussion-map.md)

## 背景・現状の課題

- エンジニアとして日々新しいトピックを学ぶ際、文章だけの説明では内容を直感的に理解しづらい。（根拠: D-001）

## 目的・期待成果

- ユーザーが渡したトピックをAIが視覚的に解説するHTMLへ変換し、学習内容を把握しやすくする。（根拠: D-001）
- 生成したHTMLをWebアプリ上で閲覧・管理できるようにする。（根拠: D-001）
- 初期リリースでは、トピックを渡すと解説HTMLが生成される体験を最優先する。（根拠: D-005）

## 成功指標

- 受け入れられる生成結果は、HTML形式であることの機械検証に合格している。（根拠: D-006、D-031）
- 生成HTMLによる学習効果は要件上の測定対象外とし、受け入れ判定には使用しない。（根拠: D-029）
- 利用継続など、その他のプロダクト成果指標は設けていない。（根拠: D-029）

## 利用者・関係者

- 当初の主利用者: HTMLを生成・管理する単一のユーザー。（根拠: D-002）
- 管理者: HTMLの生成・管理権限を持つ主利用者。生成済みHTMLを他ユーザーへ公開するか承認する。（根拠: D-002、D-026）
- 閲覧者: 主利用者以外のユーザー。Googleログインなしで、管理者が公開を承認したHTMLだけを閲覧でき、生成・管理はできない。（根拠: D-003、D-025〜D-027）

## スコープ

### 対象内

- 自然言語のプロンプトによるトピックと生成指示の入力。（優先度: 最優先、根拠: D-001、D-005、D-012）
- AIによるグラフィカルな解説HTMLの生成。（優先度: 最優先、根拠: D-001、D-005）
- 機械検証に合格したHTMLを管理者が確認し、自然言語の修正指示を与えて再生成する反復作業。（根拠: D-031、D-032）
- 生成したHTMLの閲覧、タグ管理、サイト内での配置場所の管理。（根拠: D-001、D-015〜D-019）
- 生成HTMLのバージョン履歴管理と、公開表示するHTMLの過去バージョンへの切り替え。（根拠: D-034、D-035）
- アプリ独自のカテゴリ制限を設けず、自然言語で表せるトピックを生成対象として受け付ける。（根拠: D-014）
- 管理者によるGoogleアカウントでのログイン。（根拠: D-003、D-025、D-027）
- 主利用者以外のユーザーに対する、生成・管理権限を持たない閲覧専用アクセス。（根拠: D-003、D-025）

### 対象外

- トピックのカテゴリによる除外は設けない。（根拠: D-014）
- ユーザーがこれまで要望として挙げた項目を、初期リリースの対象外にはしない。（根拠: D-025）

## 機能要件

- FR-001: 主利用者がトピックを含む自然言語のプロンプトを渡すと、AIがそのトピックをグラフィカルに解説するHTMLを生成できる。追加の生成指示は任意とする。（根拠: D-001、D-005、D-012、D-013）
- FR-002: 主利用者が機械検証に合格した生成済みHTMLをWebアプリ上で閲覧し、内容を確認できる。（根拠: D-001、D-010、D-011、D-031、D-032）
- FR-003: 主利用者が新しいタグを作成し、タグ名を変更し、機械検証に合格した生成済みHTMLにタグを付けたり外したりできる。また、Webサイト上での配置場所を管理でき、配置先の名前を任意に設定できる。（根拠: D-001、D-015〜D-024、D-030、D-031）
- FR-004: 生成結果がHTML形式であるかを機械的に検証する。（根拠: D-006、D-031）
- FR-005: HTML生成処理自体が失敗した場合、または生成結果がHTML形式の機械検証に失敗した場合、利用者にエラーを表示して最大3回まで自動再試行する。3回失敗した時点で自動再試行を終了して最終エラーを表示し、その後は管理者の操作で再試行できる。（根拠: D-007〜D-009、D-028、D-031、D-039）
- FR-006: 主利用者がHTML生成ごとの成功・失敗を要約ログで確認でき、失敗時には失敗理由を確認できる。（根拠: D-010、D-011）
- FR-007: 事前登録された1つのGoogleメールアドレスを持つ利用者が、管理者としてログインできる。（根拠: D-002、D-003、D-025、D-027、D-037）
- FR-008: 主利用者以外のユーザーは、Googleログインなしで管理者が公開を承認したHTMLを閲覧できるが、HTMLの生成および管理はできない。（根拠: D-003、D-025〜D-027）
- FR-009: 管理者は、機械検証に合格したHTMLを確認し、「ここはこうして」などの自然言語による修正指示を与えてHTMLを再生成できる。（根拠: D-031、D-032）
- FR-010: 管理者は生成HTMLのバージョン履歴を確認し、公開表示するHTMLを過去のバージョンへ切り替えられる。また、公開中のHTMLを非公開へ戻せる。（根拠: D-026、D-034〜D-036）
- FR-011: 管理者は機械検証に合格した未承認のHTMLバージョンを公開承認でき、承認したバージョンを他ユーザーへの公開表示版にできる。（根拠: D-026、D-031）

## 業務ルール・データ要件

- BR-001: 初期段階では、HTMLを生成・管理する主体は1人を想定する。（根拠: D-002）
- BR-002: 生成済みHTMLは、管理者が承認した場合に限り他ユーザーへの公開対象となる。（根拠: D-003、D-026）
- BR-003: 生成HTMLに共通する機械的な最低要件は、生成結果がHTML形式であると判定できることである。特定ブラウザ・端末での表示保証は機械検証の合格条件に含めない。（根拠: D-006、D-031）
- BR-004: HTML生成処理自体の失敗とHTML形式の機械検証失敗には同じ再試行ルールを適用する。最大3回まで自動再試行し、3回失敗した時点で自動再試行を終了し、その後は管理者の操作によって開始する。（根拠: D-008、D-028、D-031、D-039）
- BR-005: HTML形式の機械検証に失敗した生成は、失敗した生成記録として利用者が確認できる状態で保持する。（根拠: D-010、D-011、D-031）
- BR-006: 利用者向けの生成ログには成功・失敗と失敗理由を含め、詳細な内部ログは表示しない。（根拠: D-011）
- BR-007: 入力は固定項目に分解せず自然言語のプロンプトとして受け付け、有効な入力には最低限トピックが含まれていなければならない。追加の生成指示は任意とする。（根拠: D-012、D-013）
- BR-008: 初期リリースでは、アプリ独自にHTML生成の対象外とするトピックカテゴリを設けない。（根拠: D-014）
- BR-009: サイト内の配置場所は、主利用者が任意の名前を設定できる配置先を単位として扱い、あらかじめ固定された候補だけに限定しない。配置場所はHTML全体に紐付き、公開するバージョンを切り替えても維持する。（根拠: D-016、D-017、D-035、D-040）
- BR-010: 初期リリースのタグ管理には、タグの新規作成、タグ名の変更、機械検証に合格した生成済みHTMLへのタグ付与、タグ解除を含める。タグはHTML全体に紐付ける。（根拠: D-019、D-020、D-022〜D-024、D-030、D-031、D-041）
- BR-011: 生成・管理権限を持つ主利用者と、閲覧だけを許可されるその他のユーザーを区別する。（根拠: D-003、D-025）
- BR-012: 管理者による承認前の生成済みHTMLは、他ユーザーへ公開しない。（根拠: D-026）
- BR-013: 管理者が公開を承認したHTMLの閲覧には、Googleログインを要求しない。（根拠: D-027）
- BR-014: HTML形式の機械検証に失敗した生成記録にはタグを付けない。（根拠: D-030、D-031）
- BR-015: 機械検証に合格した生成結果は管理者による内容確認の対象とし、修正が必要な場合は自然言語の修正指示を入力して再生成する。（根拠: D-031、D-032）
- BR-016: 公開済みHTMLを再生成しても、新しいバージョンを管理者が承認するまでは従来の承認済みバージョンを公開し続ける。（根拠: D-026、D-034）
- BR-017: 再生成したHTMLの内容はバージョンとして履歴に保持する。管理者が過去バージョンへ公開表示を切り替える操作は、そのバージョンの公開承認を兼ねる。（根拠: D-026、D-035、D-038、D-041）
- BR-018: 管理者が公開承認を取り消したHTMLは非公開となり、他ユーザーは閲覧できない。（根拠: D-026、D-036）
- BR-019: 管理者権限は事前登録した1つのGoogleメールアドレスだけに付与し、それ以外のアカウントには生成・管理操作を許可しない。（根拠: D-002、D-003、D-037）
- BR-020: タグの状態はHTMLのバージョン管理対象に含めない。公開表示するHTMLのバージョンを切り替えてもタグは巻き戻さず、HTML全体の現在のタグ状態を維持する。（根拠: D-035、D-041）
- BR-021: 生成HTMLは外部サイト・外部サービスへ通信できる。ただし、アプリの認証情報および管理データにはアクセスできない。（根拠: D-033、D-042）

## 非機能要件

- NFR-001: 利用者向けログに、要約範囲を超える詳細な内部ログを表示しない。（根拠: D-011）
- NFR-002: 生成HTMLは、アプリの認証情報および管理データへアクセスできない隔離された環境で表示する。（根拠: D-033）
- NFR-003: 生成HTMLから外部サイト・外部サービスへのネットワーク通信は、一律には禁止しない。（根拠: D-042）
- NFR-004: 初期リリースでは、HTML生成完了までの上限時間および目標時間を設けない。（根拠: D-043）
- NFR-005: 初期リリースでは、生成HTMLについて特定のブラウザまたは端末を対象とした表示保証を設けない。（根拠: D-031、D-045）
- NFR-006: 初期リリースでは、管理画面および生成HTMLに対する測定可能なアクセシビリティ要求を設けない。（根拠: D-046）
- その他の品質水準は未確認。

## 制約・依存関係

- CON-001: 初期リリースのHTML生成にはCodex app-serverを利用し、他の生成基盤へ置き換えない。（根拠: D-005、D-044）

## 前提

- ASM-001: 初期リリースでは、生成・管理権限を持つユーザーは1人である。（依頼文から確認済み、根拠: D-002）
- ASM-002: Googleアカウントでのログインを初期リリースに含める。（確認済み、根拠: D-003、D-025）
- ASM-003: 生成HTMLの具体的な説明内容はプロンプトによって制御し、共通要件としてHTML形式であるかを機械検証する。（確認済み、根拠: D-006、D-031）

## リスク

- RISK-001: 生成HTMLによる学習効果は測定しないため、生成結果が実際に学習へ役立ったかは要件上の受け入れ判定では保証しない。（受容済み、根拠: D-001、D-029）
- RISK-003: 失敗理由の説明が抽象的すぎる場合、利用者が次の入力や再生成で問題を解消できない可能性がある。（根拠: D-011）
- RISK-004: アプリ独自の対象外トピックを設けなくても、HTML生成に利用する外部サービスの制約により生成できない場合がある。この場合は共通の再試行・終了ルールを適用する。（根拠: D-014、D-039、DD-001）
- RISK-005: 生成HTMLの実行環境から認証情報や管理データへアクセスされるリスクは、アプリ本体から隔離して表示することで抑制する。（対策確定、根拠: D-033）
- RISK-006: 生成HTMLの外部通信を一律禁止しないため、外部サービスによる通信記録や閲覧者の追跡が発生する可能性がある。（受容、根拠: D-042）

## 受け入れ基準

- AC-001: Given 主利用者が解説してほしいトピックを含む自然言語プロンプトを用意している / When そのプロンプトを生成対象として渡す / Then 当該トピックを視覚的に解説するHTMLが生成される。（対応: FR-001、BR-007、根拠: D-001、D-012、D-013）
- AC-002: Given 解説HTMLが生成済みである / When 主利用者がWebアプリで対象を選ぶ / Then 生成されたHTMLの内容を閲覧できる。（対応: FR-002、根拠: D-001）
- AC-003: Given 解説HTMLが生成された / When 機械検証を行う / Then 生成結果がHTML形式であるかが判定され、HTML形式と判定できた結果だけが検証に合格する。（対応: FR-004、BR-003、根拠: D-006、D-031）
- AC-004: Given 生成結果がHTML形式の機械検証に失敗し、自動再生成の失敗回数が3回未満である / When 失敗が確定する / Then 利用者にエラーが表示され、HTMLの再生成が自動で開始する。（対応: FR-005、根拠: D-007、D-028、D-031）
- AC-005: Given HTMLの自動再生成が繰り返し機械検証に失敗している / When 自動再生成の失敗が3回に達する / Then 自動再生成を終了する。（対応: FR-005、BR-004、根拠: D-008、D-028、D-031）
- AC-006: Given HTMLの自動再生成が3回失敗した / When 自動再生成を終了する / Then 利用者に最終エラーが表示される。（対応: FR-005、根拠: D-009、D-028）
- AC-016: Given HTMLの自動再生成が3回失敗して終了している / When 管理者が再生成を操作する / Then 新たな再生成が開始する。（対応: FR-005、BR-004、根拠: D-028）
- AC-007: Given HTML生成が完了または失敗している / When 主利用者が当該生成のログを確認する / Then 成功・失敗の結果を確認でき、失敗時には失敗理由を確認できる。（対応: FR-006、BR-005、BR-006、根拠: D-010、D-011）
- AC-008: Given 主利用者が生成ログを確認する / When ログが表示される / Then 詳細な内部ログは表示されず、結果と失敗理由の要約だけが表示される。（対応: FR-006、BR-006、NFR-001、根拠: D-011）
- AC-009: Given 機械検証に合格した生成済みHTMLがある / When 主利用者が当該HTMLにタグを付ける / Then 付与したタグを当該HTMLに関連付けて確認できる。（対応: FR-003、BR-010、根拠: D-019、D-020、D-030、D-031）
- AC-010: Given 機械検証に合格した生成済みHTMLがある / When 主利用者が任意の名前を持つ配置先を設定する / Then 当該HTML全体のサイト内掲載場所に設定結果が反映され、公開バージョンを切り替えても維持される。（対応: FR-003、BR-009、根拠: D-015〜D-017、D-031、D-035、D-040）
- AC-011: Given 生成済みHTMLにタグが付いている / When 主利用者が当該タグを外す / Then 当該HTMLとタグの関連付けが解除されたことを確認できる。（対応: FR-003、BR-010、根拠: D-022）
- AC-012: Given 主利用者が新しいタグを必要としている / When タグを作成する / Then 作成したタグを生成済みHTMLへの付与対象として確認できる。（対応: FR-003、BR-010、根拠: D-023）
- AC-013: Given 作成済みタグがある / When 主利用者がタグ名を変更する / Then 変更後の名前が当該タグとその付与先に反映される。（対応: FR-003、BR-010、根拠: D-024）
- AC-014: Given 利用者のGoogleメールアドレスが管理者として事前登録されている / When Googleログインを行う / Then 管理者としてWebアプリへログインできる。（対応: FR-007、BR-019、根拠: D-002、D-003、D-025、D-027、D-037）
- AC-015: Given 管理者が生成済みHTMLの公開を承認している / When Googleログインしていない他ユーザーが当該HTMLへアクセスする / Then HTMLを閲覧できる一方、生成・管理操作は実行できない。（対応: FR-008、BR-002、BR-011〜BR-013、根拠: D-003、D-025〜D-027）
- AC-017: Given 機械検証に合格したHTMLがある / When 管理者が当該HTMLを開く / Then 生成された内容を確認できる。（対応: FR-002、FR-009、BR-015、根拠: D-031、D-032）
- AC-018: Given 管理者が生成HTMLの内容を確認して修正が必要だと判断した / When 自然言語の修正指示を入力する / Then 指示を反映するHTMLが再生成され、機械検証の対象になる。（対応: FR-004、FR-009、BR-015、根拠: D-031、D-032）
- AC-019: Given 管理者または未ログイン閲覧者が生成HTMLを開く / When 当該HTMLが表示される / Then 生成HTMLからアプリの認証情報および管理データへアクセスできない。（対応: NFR-002、根拠: D-033）
- AC-020: Given 公開中のHTMLに対して新しいバージョンを再生成している、または新しいバージョンが未承認である / When 他ユーザーが公開HTMLへアクセスする / Then 従来の承認済みバージョンを引き続き閲覧できる。（対応: FR-008、FR-009、BR-016、根拠: D-026、D-032、D-034）
- AC-021: Given 生成HTMLに複数のバージョンが保持されている / When 管理者が過去バージョンを公開表示版として選択する / Then その操作が当該バージョンの公開承認として扱われ、他ユーザーへ表示されるHTMLが選択した過去バージョンへ切り替わる。（対応: FR-010、BR-017、根拠: D-026、D-035、D-038）
- AC-022: Given HTMLが公開中である / When 管理者が公開承認を取り消す / Then 当該HTMLは非公開となり、他ユーザーは閲覧できなくなる。（対応: FR-010、BR-018、根拠: D-026、D-036）
- AC-023: Given 利用者のGoogleメールアドレスが管理者として事前登録されていない / When Googleログインを試みる / Then HTMLの生成・管理権限は付与されない。（対応: FR-007、BR-011、BR-019、根拠: D-003、D-037）
- AC-024: Given 機械検証に合格した未承認のHTMLバージョンがある / When 管理者が当該バージョンを公開承認する / Then 当該バージョンが公開表示版となり、他ユーザーが閲覧できる。（対応: FR-008、FR-011、BR-002、BR-012、根拠: D-026、D-031）
- AC-025: Given HTML生成サービスのエラーなどで生成結果を取得できず、自動再試行の失敗回数が3回未満である / When 失敗が確定する / Then 利用者にエラーが表示され、生成処理が自動で再試行される。（対応: FR-005、BR-004、根拠: D-039）
- AC-026: Given 生成結果を取得できない状態が自動再試行でも続いている / When 自動再試行の失敗が3回に達する / Then 自動再試行を終了し、利用者に最終エラーを表示する。（対応: FR-005、BR-004、根拠: D-039）
- AC-027: Given 生成結果を取得できない状態が3回続いて自動再試行が終了している / When 管理者が再試行を操作する / Then 新たな生成処理が開始する。（対応: FR-005、BR-004、根拠: D-039）
- AC-028: Given HTML全体にタグが付いている / When 管理者が公開表示するHTMLを別のバージョンへ切り替える / Then HTML全体のタグは切り替え前の状態を維持し、過去時点のタグ状態へは戻らない。（対応: FR-003、FR-010、BR-010、BR-020、根拠: D-035、D-041）
